# Brano redesign v1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Brano its own look: an "Espressivo" library and navigation, and a "Vinile" player coloured by the album, without making the app slower.

**Architecture:** Visual changes only, in `app/src/main/java/app/brano/ui/**`, plus one new setting.
- The theme gets a lilac fallback seed, custom `Shapes` and `Typography`, and shared shapes.
- The player colours are a pure function of the album seed already computed by `ArtworkSeedLoader`, so no extra image work is done.
- The vinyl disc rotates through `graphicsLayer`, with no recomposition per frame.

**Tech Stack:** Kotlin, Jetpack Compose with Material 3, DataStore, JUnit4, Truth, Robolectric, mockk.

**Spec:** `docs/superpowers/specs/2026-11-09-redesign-design.md`

## Global Constraints

- **No expensive effects:** no `Modifier.blur`, `RenderEffect`, custom shaders, video or downloaded fonts. The serif is `FontFamily.Serif`; the heavy sans is the system font with `FontWeight.Black`.
- **Lilac fallback seed:** `Color(0xFF7C5CFF)`.
- **Shapes:**
  - `CoverShape` = `RoundedCornerShape(topStart = 14.dp, topEnd = 30.dp, bottomEnd = 14.dp, bottomStart = 30.dp)`;
  - `PillShape` = `RoundedCornerShape(50)`;
  - theme `Shapes`: small 12dp, medium 20dp, large 28dp, extraLarge 36dp.
- **Disc rotation:** one turn every 20 s. It stops in pause and stays still when "Disco che gira" is off. The setting is on by default.
- **Player colours:** the player is always dark, in both themes. Colour changes animate over 600 ms, like the current theme.
- **Startup and scrolling:** cold start on the emulator within +50 ms of today (~0.4 s). The track list must not drop frames visibly.
- **Tests and lint:** the existing 190 tests stay green and lint has 0 errors.
- **Environment, Git Bash:**
  - `export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"`;
  - adb needs `MSYS_NO_PATHCONV=1`;
  - tests run with `./gradlew :app:testDebugUnitTest`.

## Review Focus

1. **Album with grey or near-black art, or no art:** player text must stay readable (contrast ≥ 4.5). Pinned in Task 2.
2. **Pause, then play:** the disc resumes from the angle where it stopped, without jumping back to 0°. Pinned in Task 4 with the pure `discAngleAfter` function.
3. **"Colori dalla copertina" off on Android 12+:** keeps the system dynamic scheme; on Android < 12 it uses lilac. Pinned in Task 1.
4. **Changing track inside the same album:** the colours must not flicker. The seed flow already uses `distinctUntilChanged` on `albumId`; keep it.
5. **Settings from v1 without the new key:** "Disco che gira" reads as `true`. Pinned in Task 3.

### Task 2: Player colours

**Files:**
- Create: `app/src/main/java/app/brano/ui/theme/PlayerColors.kt`
- Test: `app/src/test/java/app/brano/ui/theme/PlayerColorsTest.kt` (Robolectric, like `DynamicColorsTest`)

**Interfaces:**
- Produces:
  - `data class PlayerColors(val glow: Color, val deep: Color, val text: Color, val accent: Color)`;
  - `fun playerColors(seed: Color?): PlayerColors`, where `null` is treated as `LilacSeed`.

The colours use the seed hue with saturation clamped to 0.35–0.85:
- `glow`: lightness 0.50;
- `deep`: lightness 0.12;
- `accent`: lightness 0.72;
- `text`: `Color(0xFFFFF7ED)`.

Low-saturation (grey) seeds keep their hue but use saturation 0.15, so a black-and-white cover gives a neutral player.

- [ ] **Step 1: Write the failing tests**

```kotlin
private fun contrast(a: Color, b: Color) = ColorUtils.calculateContrast(a.toArgb(), b.toArgb())

@Test fun `text is readable on deep for many seeds`() {
    listOf(Color.Red, Color.Yellow, Color.Blue, Color.White, Color.Black, Color.Gray, Color(0xFF7CFC00), null)
        .forEach { assertThat(contrast(playerColors(it).text, playerColors(it).deep)).isAtLeast(4.5) }
}
@Test fun `null seed equals lilac`() = assertThat(playerColors(null)).isEqualTo(playerColors(LilacSeed))
@Test fun `grey seed gives a neutral deep`() {
    val hsl = FloatArray(3); ColorUtils.colorToHSL(playerColors(Color.Gray).deep.toArgb(), hsl)
    assertThat(hsl[1]).isAtMost(0.2f)
}
@Test fun `accent is lighter than glow`() {
    val p = playerColors(Color.Blue)
    assertThat(p.accent.luminance()).isGreaterThan(p.glow.luminance())
}
```

- [ ] **Step 3: Implement `VinylDisc`**
  - **Angle state:** keep the angle in `remember { mutableFloatStateOf(0f) }`.
  - **Animation loop:** `LaunchedEffect(spinning)` → while spinning, call `withFrameMillis` and set `angle = discAngleAfter(startAngle, now - start)`.
    - Read the angle only inside `Modifier.graphicsLayer { rotationZ = angle }`, so frames don't recompose.
    - When the system animator scale is 0 (`Settings.Global.ANIMATOR_DURATION_SCALE`), don't start the loop.
  - **Drawing:**
    - an `Artwork(albumId, shape = CircleShape)` inside a 10dp ring of `colors.deep`;
    - a 1dp outer line of `colors.glow` at 35% alpha;
    - a small centre hole (12dp, `colors.deep`) drawn with `drawBehind`/`drawWithContent`.
  - **Swipe:** keep the existing horizontal swipe gesture from `SwipeableArtwork` on the disc.

- [ ] **Step 4: Restyle `PlayerScreen`**
  - **Colours:**
    - `val colors = playerColors(seed)`, with each field animated by `animateColorAsState(tween(600))`;
    - `PlayerViewModel` exposes `seedColor` already, so the screen collects it.
  - **Background:** draw it in `Modifier.drawBehind` with `Brush.radialGradient(0f to glow, 0.6f to deep, 1f to Color(0xFF0B0806))`, centre at (50% width, 25% height), radius = 1.2 × width.

    - all content uses `colors.text`, provided through `CompositionLocalProvider(LocalContentColor provides colors.text)`;
    - artist and album lines at 70% alpha.
  - **Title:** `FontFamily.Serif`, `FontStyle.Italic`, 22sp.
  - **Play/pause:** a 64dp circle filled with `colors.text`, icon in `colors.deep`.
  - **Slider:** `SliderDefaults.colors(thumbColor = accent, activeTrackColor = accent, inactiveTrackColor = text.copy(alpha = .2f))`.
  - **Disc:** replace `SwipeableArtwork` with `VinylDisc(spinning = state.isPlaying && spinDisc)`.
  - **Status bar:** the screen is always dark, so set the status bar icons to light while it is shown and restore them on dispose. Use `WindowCompat.getInsetsController(window, view).isAppearanceLightStatusBars`.
